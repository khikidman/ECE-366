How we can run the MIPS program to find if a given number m is odd:
1) Open the MARS MIPS simulator and the mips2.asm file.
2) Change the value of m in the .data section to the desired nonnegative integer.
3) Click Assemble and then Run to execute the program. The result (1 if m is odd, 0 if m is even) will appear in the Run I/O window. The result is also stored in memory at the label result.
