**How we can run the MIPS program to get the n th Fibonacci number for a given n:**
1) Open the MARS MIPS simulator.
2) Open the mips1.asm file.
3) Change the value of n in the .data section to the desired number.
4) Click Assemble, then Run to execute the program.
5) The nth Fibonacci number will appear in the Run I/O window. The result is also stored in memory.
